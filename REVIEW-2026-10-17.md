# Know-It-All review, 2026-10-17

Sources: 8 Haiku reviewers (design hub, quiz-family screens, geo/names/charts/lists games, question bank, game datasets, performance, dead code, new-game ideas). Two reviewers (design-games-b, bugs) returned nothing. The synthesis lead (Sonnet) spot-checked every high-severity finding and every claimed wrong answer against the code and data on the `dev` branch. Chrome could not capture a 390 px phone layout (the viewport stayed at 1707 px), so **phone layout is still UNVERIFIED**; the first package task that touches layout must check it.

## Verdict

The site works and the content is in good shape: lint passes, 133 logic tests pass, the validator passes, and a 250-item sample of the question bank found no confident factual error. What makes it look "cheap" is the visual system, not the features. Only colour is tokenised; radii, spacing, type sizes and shadows are literals (seven radii, about thirty font sizes). Six accent hues compete on one screen. Cards use blurred glass and glowing gradient buttons. Cards are decorated with emoji while the nav uses line icons. Three fonts are loaded (Cinzel's fantasy look in the logo is the loudest tell). The muted text colour (#64748b) measures 3.2 to 3.96:1 against the surfaces, which fails WCAG AA for body text. Keyboard focus has no visible style at all (the only `:focus-visible` rule is in a stylesheet that is never imported). The fix is a single design system, then adoption screen by screen: flat surfaces, one accent per section, one icon set, one result-screen pattern. Beyond design: the main JS chunk is 1,147 KB because the whole 924 KB question bank and the flashcard decks load before the home screen; there is a real pile of dead code (an unimported 185-line stylesheet, three unused images, about 16 dead CSS classes, six dead exports); Four by four has 21 items that fit two groups and heavily reused wordplay pools; and a few content items need tidying (one answer leaked in its own question). Several Haiku claims did not hold up and are rejected below.

## Design brief

See the section below (also returned to the orchestrator). Direction: an "evening edition" look. Flat, editorial, confident, dark only for now.

**Fonts.** Display and question text: Newsreader (Google Fonts, already loaded; weights 500, 600, italic 400). UI, body and buttons: Inter (400, 500, 600, 700). Remove Cinzel. Load with `<link rel="preconnect">` and a stylesheet link in `index.html`, not CSS `@import`. Fallbacks: Newsreader, Georgia, "Times New Roman", serif; Inter, system-ui, -apple-system, "Segoe UI", Roboto, sans-serif. `font-variant-numeric: tabular-nums` on scores, timers and counts. All form controls `font: inherit`.

**Colour tokens (dark).** Surfaces: `--bg #0b1120`, `--surface-1 #121a2e`, `--surface-2 #1a243d`, `--surface-3 #243049`. Lines: `--line rgba(255,255,255,.08)`, `--line-strong rgba(255,255,255,.16)`. Ink: `--ink #f3f5f9` (14 to 17:1), `--ink-2 #aab4c6` (7 to 9:1), `--ink-3 #8591a8` (4.85 to 5.9:1, the floor; nothing dimmer for text). Brand: `--brand #f5b83d`, `--on-brand #1a1305` (10.4:1). Right/wrong only: `--correct #34d399`, `--wrong #fb7185`, with `-bg` tints at 12% via `color-mix`. Focus: `--focus #7aa2ff`. One accent per section, each at least 6.2:1 on every surface: weekend `#f5b83d`, geo `#4ecb9a`, pop `#ff8f6b`, words `#c49bff`, lab `#5fd0e0`. A section root sets `--accent`; hover borders, record text, icon colour, progress fills and the primary button follow it. A screen uses only the neutral ramp, its one accent, and correct/wrong. Contrast ratios measured 2026-10-17.

**Type scale (16px base).** `--fs-xs .75rem` (pills, eyebrow), `--fs-sm .875rem` (labels, secondary), `--fs-md 1rem` (body), `--fs-lg 1.25rem` (card titles), `--fs-xl 1.625rem` (screen titles, Newsreader 600), `--fs-2xl clamp(2rem, 5vw, 3rem)` (score numerals, Newsreader 600). Question text: Newsreader 600, `clamp(1.35rem, 3.5vw, 1.75rem)`, line-height 1.3. Body line-height 1.5, headings 1.2. Eyebrow: Inter 600, `--fs-xs`, uppercase, letter-spacing .08em, `--ink-2`. Weights used: 400, 500, 600.

**Spacing and shape.** 4px base: `--s-1 4`, `--s-2 8`, `--s-3 12`, `--s-4 16`, `--s-5 24`, `--s-6 32`, `--s-7 48`. Page gutter 16px on phones, 24px from 720px. Hub max width 960, game and quiz column 720. Radii: `--r-control 12px` (buttons, inputs, option rows, tiles), `--r-card 16px`, `--r-pill 999px`. No other radius.

**Borders, shadows, motion.** Cards are `--surface-1` with a 1px `--line` border and no shadow at rest. Raised layer (sticky action bar, menus): `--shadow-raised: 0 8px 24px rgba(0,0,0,.35)`. No glow, no `backdrop-filter`, no gradients (body radial gradients removed). Hover: border to `--line-strong` (hub cards: section accent at 60%). Press: scale .98, 120ms. Transitions 120 to 200ms ease-out. `prefers-reduced-motion` disables transitions and confetti. Focus: `:focus-visible { outline: 2px solid var(--focus); outline-offset: 2px }` on every interactive element; never remove an outline without a replacement.

**Components.** Button: 44px minimum height, padding 0 20px, `--r-control`, Inter 600 .9375rem. Primary is a solid `--accent` fill with dark text, no gradient; secondary is transparent with a `--line-strong` border; tertiary is a text button in `--ink-2`; danger is a text button in `--wrong`, only inside a confirm. One primary per screen. Card: `--surface-1`, `--line`, `--r-card`, padding 24 (16 on phones). Hub card: 40px `--surface-2` tile holding a 24px lucide icon in the section accent; title Inter 600 1rem; blurb `--ink-2` .875rem, two lines max; record line at the bottom in `--fs-xs` in the accent. Hub grid `repeat(auto-fill, minmax(240px, 1fr))`, gap 16. Section header: eyebrow title with a 3px accent rule, blurb in Newsreader italic `--ink-2`. Pill: one `.pill`, 24px high, padding 0 10px, `--fs-xs` 600, variants neutral, accent, correct, wrong. Option row (quiz answers): full width, 56px minimum height, `--surface-2`, `--line`, `--r-control`, 28px letter key (A to D) on the left; hover `--surface-3`; selected 2px accent; revealed correct is `--correct-bg` with a check icon; revealed wrong is `--wrong-bg` with an x icon; others dim to .6. State via `data-state`, never `!important`. AnswerRow (names, list, chart boards, Four by four tiles): 48px minimum, `--surface-2`, `--r-control`, states pending, got, missed, wrong via `data-state`. Input: 48px high, `--surface-2`, `--line-strong`, `--r-control`, 16px text (stops iOS zoom), focus ring.

**Result-screen pattern (one `GameResults` for every game).** Centred column: eyebrow (game name and date), hero numeral `--fs-2xl` ("18 / 25"), one-line verdict in Newsreader italic `--fs-lg`, a row of small green/red squares for the round, one primary button ("Play again"), one secondary ("Change settings"), then the answer review as AnswerRows and the most-missed items as pills.

**Header.** Left: wordmark "Know-It-All" in Newsreader 600 1.375rem with a small brand dot (no emoji, no Cinzel); it is a link, with the `h1` outside any button. Tabs are text-only with a 2px brand underline on the active one, horizontally scrollable on phones with scroll snap. Right: one streak pill and the account button. Reset moves into the account menu as a danger text button.

**Icon policy.** lucide-react only for every game, category, deck, milestone and status icon (stroke 1.75, 20px inline, 24px in tiles, `currentColor`). Flags stay as flag-icons SVGs. Emoji only inside copy for celebration or empty states and as share-grid squares; never as UI icons. A `CategoryIcon`/`GameIcon` component maps ids to lucide icons (map lives in categories.js and registry.js).

**Copy.** Sentence case, no em dashes in UI strings, counts formatted "1,500+" and derived from data.

**Responsive and accessibility.** Design 390px first; breakpoints 720 and 1024; tap targets at least 44px; no horizontal page scroll; hub is one column under 520px. Body text at least 4.5:1, large text and UI at least 3:1. Clickable things are `<button>` or `<a>`; icon-only buttons have `aria-label`; flag choices have the country as `aria-label`.

**Dark mode.** The site is dark only today. Keep `color-scheme: dark` on `:root`. Every colour is a token (no hex or rgba literals in component CSS; tints use `color-mix(in srgb, var(--x) 12%, transparent)`) so a light set can be added later under `:root[data-theme="light"]`.
